Benchmark 1.0.2

macOS: распакуйте ZIP, перенесите Benchmark.app в «Программы» и откройте его.
Windows: распакуйте ZIP и откройте Benchmark.exe в папке Benchmark.
Сохраняйте всю папку вместе с её содержимым.

Python, браузерный движок и Codex CLI уже включены. Устанавливать их отдельно не нужно.
Для исследования нужен интернет и аккаунт ChatGPT с доступом к Codex.

1. Нажмите «Загрузить Excel», выберите файл и папку исследования.
2. При необходимости нажмите «Войти через ChatGPT» и завершите вход в браузере.
3. Нажмите «Начать обработку». По умолчанию обрабатывается вся очередь.
4. Готовые результаты сохраняются после каждой компании. «Остановить» прерывает
   незавершённые задания; «Продолжить» возвращается к оставшимся компаниям.
5. Нажмите «Экспорт», чтобы открыть отчёт Excel или сохранить его копию.
   Отчёт содержит один лист и семь полей по ТЗ.

Пустое поле «Вся очередь» означает обработку всех компаний. Чтобы ограничить
количество, нажмите в поле и сразу введите число.
Сверху отображается остаток лимита Codex, если аккаунт предоставляет эти данные.
Подсказка показывает время сброса. Данные обновляются раз в минуту.

Для открытия сохранённого исследования нажмите «Открыть» и выберите папку,
содержащую state.sqlite3. Для повторного исследования одной компании выберите
её в таблице и нажмите «Повторить» в карточке справа.

Приложение открывается с пустой страницей загрузки. Ваши Excel, исследования,
результаты и учётные данные не входят в распространяемый пакет.
