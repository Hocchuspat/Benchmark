# Benchmark 1.0.2 — macOS

Исправлен нативный клавиатурный ввод в macOS-приложении. PyInstaller наследовал
консольный режим фонового обработчика и устанавливал LSBackgroundOnly=true для
всего .app. macOS запускала окно с запрещённой обычной активацией.

В Info.plist явно установлены LSBackgroundOnly=false и LSUIElement=false.
Проверка готового пакета теперь отклоняет сборки с фоновым режимом GUI.
Обычные проверки ввода Qt дополнены проверкой режима активации macOS.

Это исправление упаковки macOS. Последняя Windows-сборка — 1.0.1.
Чтобы применить обновление, завершите старый Benchmark и замените его новым
приложением. Если старое окно не закрывается, завершите процесс Benchmark
через «Мониторинг системы», после чего запустите версию 1.0.2.
