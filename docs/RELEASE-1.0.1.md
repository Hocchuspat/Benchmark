# Benchmark 1.0.1

Исправлено завершение macOS-приложения после остановки: системная команда Quit,
⌘Q и закрытие окна завершают цикл Qt после фоновой обработки. Контроллер больше
не ждёт закрытия канала вывода, если сам обработчик уже завершился.

«Вся очередь» отображается подсказкой пустого поля. Число можно сразу ввести;
очистка поля возвращает обработку всей очереди.

Итоговые XLSX и CSV содержат только семь полей по ТЗ. В XLSX один лист.
Сведения об источниках остаются в карточках и технических файлах исследования.

Добавлен остаток лимита Codex в процентах по периодам и время сброса в подсказке.
Получение выполняется через встроенный Codex без запросов к модели, раз в минуту.
При отсутствии данных индикатор скрывается. Количество оставшихся компаний не рассчитывается.

Сборки проверяются без системного Python, включая ввод числа, остановку и выход
из настоящего упакованного окна Qt. Установщик и подпись издателя не добавлены.
