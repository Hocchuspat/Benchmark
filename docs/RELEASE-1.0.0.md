# Benchmark 1.0.0

Первая клиентская версия для подготовки отчёта о компаниях из Excel.
Приложение включает Python, Qt/Chromium, Codex CLI, правила исследования и скиллы.
Для работы нужен интернет и вход через ChatGPT; API-ключи не используются.

В интерфейсе доступны загрузка Excel, параллельная обработка двух компаний,
прогресс, остановка и продолжение, повтор одной компании и экспорт отчёта.
Карточка справа показывает деятельность, функции и источники. Статусы:
«Не обработан», «Обрабатывается», «Обработан». Сайт можно скопировать с анимированным
подтверждением. Время обработки показано сверху; паузы не учитываются.

Каждая готовая карточка сохраняется отдельно. При остановке незавершённые задания
возвращаются в очередь. Сохранённые результаты доступны при следующем открытии.

Пакеты находятся в `dist/1.0.0/`: macOS Apple Silicon — `.app` и ZIP,
Windows x64 — ZIP с папкой `Benchmark`. Для установки используйте `START.txt`.
Рядом с архивами находятся контрольные суммы SHA-256.

Локальная macOS-сборка имеет ad-hoc подпись. Подпись Developer ID, нотариализация,
Windows Authenticode, установщик и автоматическое обновление в эту версию не входят.
Исходный Excel, исследования и учётные данные не включаются в распространяемые файлы.
